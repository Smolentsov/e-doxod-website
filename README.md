Статический сайт на GitHub Pages для продажи цифровых продуктов через Telegram-бот [@e_doxod_bot](https://t.me/e_doxod_bot).


## 🚀 Быстрый старт (деплой на GitHub Pages)

### Шаг 1: Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com) и авторизуйтесь
2. Нажмите зелёную кнопку **New** (или «+» → New repository)
3. Название репозитория: `e-doxod-website`
4. Выберите **Public** (публичный)
5. Нажмите **Create repository**

### Шаг 2: Загрузите файлы
**Вариант А — через веб-интерфейс (простой):**
1. В новом репозитории нажмите **uploading an existing file**
2. Перетащите ВСЕ файлы и папки проекта в окно загрузки
3. В поле «Commit changes» напишите: `Initial commit`
4. Нажмите **Commit changes**

**Вариант Б — через Git (для продвинутых):**
```bash
git clone https://github.com/ВАШ_НИК/e-doxod-website.git
cd e-doxod-website
# скопируйте сюда все файлы проекта
git add .
git commit -m "Initial commit"
git push origin main
```

### Шаг 3: Включите GitHub Pages
1. В репозитории перейдите во вкладку **Settings** (Настройки)
2. В левом меню выберите **Pages**
3. В разделе «Source» выберите ветку **main** и папку **/(root)**
4. Нажмите **Save**
5. Через 1–5 минут сайт будет доступен по адресу: `https://ВАШ_НИК.github.io/e-doxod-website`

### Шаг 4: Привяжите свой домен e-doxod.ru
1. В папке проекта найдите файл **CNAME** (уже создан, содержит `e-doxod.ru`)
2. Убедитесь, что он загружен в корень репозитория
3. Зайдите в панель управления вашего регистратора домена (где покупали e-doxod.ru)
4. Найдите раздел «DNS-записи» или «Управление DNS»
5. Добавьте следующие записи:

| Тип | Имя | Значение | TTL |
|-----|-----|----------|-----|
| A | @ | 185.199.108.153 | 3600 |
| A | @ | 185.199.109.153 | 3600 |
| A | @ | 185.199.110.153 | 3600 |
| A | @ | 185.199.111.153 | 3600 |
| CNAME | www | ВАШ_НИК.github.io | 3600 |

6. Сохраните изменения. DNS обновится в течение 15 минут — 24 часов.
7. В GitHub Pages (Settings → Pages) введите `e-doxod.ru` в поле «Custom domain» и нажмите **Save**
8. Поставьте галочку **Enforce HTTPS** (через некоторое время, когда SSL-сертификат будет готов)

## ⚙️ Настройка перед запуском

### 1. Добавьте свои изображения
- Логотип: положите в `images/logo.png` (рекомендуемый размер: 512×512 px)
- OG-изображение для соцсетей: `images/og-image.jpg` (1200×630 px)
- Фавикон: `images/favicon.png`
- Apple touch icon: `images/apple-touch-icon.png`
- Hero-изображение: `images/hero-mockup.png`

### 2. Заполните реквизиты
В файлах найдите и замените плейсхолдеры:
- `[ФИО]` — ваше полное имя
- `[ИНН]` — ИНН индивидуального предпринимателя
- `[ОГРНИП]` — ОГРНИП
- `[Юридический адрес]` — ваш юридический адрес

Файлы, где нужно заменить:
- `index.html` (футер)
- `product.html` (футер)
- `contacts.html` (реквизиты)
- `privacy.html` (контакты)
- `offer.html` (реквизиты продавца)

### 3. Подключите аналитику
В `js/script.js` найдите строку:
```javascript
gaId: 'G-XXXXXXXXXX',
```
Замените `G-XXXXXXXXXX` на ваш идентификатор Google Analytics 4.

Также раскомментируйте блок Yandex.Metrika в `index.html`, если используете Яндекс.Метрику.

### 4. Настройте форму обратной связи
В `contacts.html` форма сейчас работает через `alert()`. Для реальной работы:
- Подключите Google Forms (создайте форму, получите URL для отправки)
- Или настройте отправку через Telegram-бота (через Bot API)
- Или используйте сервисы: Tally.so, Typeform, Formspree

## 📝 Как добавить новый товар

1. Откройте `index.html` и `product.html`
2. Найдите блок с классом `products-grid`
3. Скопируйте любой блок `product-card`:

```html
<div class="product-card reveal">
    <span class="product-tag">КАТЕГОРИЯ</span>
    <h3>Название товара</h3>
    <p>Описание товара</p>
    <div class="product-price">ЦЕНА ₽</div>
    <a href="https://t.me/e_doxod_bot?start=site_product_N" class="btn btn-primary" data-track="product_N" style="width:100%" target="_blank" rel="noopener">Купить в боте</a>
</div>
```

4. Вставьте после последнего товара
5. Измените `site_product_N` на уникальный код (например, `site_product_11`)
6. Сохраните и загрузите изменения на GitHub

## 📊 Отслеживание конверсий

Все кнопки имеют атрибут `data-track` с уникальным значением. При клике событие логируется в консоль браузера. После подключения Google Analytics события будут отправляться автоматически.

Основные события для отслеживания:
- `hero_main_cta` — главная кнопка на главной
- `header_bot` — кнопка в шапке
- `product_1` ... `product_10` — покупка конкретного товара
- `wb_unit` / `ozon_unit` — шаблоны юнит-экономики
- `white_label` — white-label
- `footer_cta` — кнопка внизу страницы
- `site_widget` — плавающая кнопка Telegram
